# Organiza Festa

O Organiza Festa é um sistema desenvolvido em Python com o objetivo de auxiliar na organização e no gerenciamento de eventos.

O projeto foi criado para facilitar o cadastro de eventos, o controle de orçamento e o acompanhamento dos gastos realizados durante a preparação de cada evento.

## O que o sistema faz?

O sistema permite:

- Cadastrar eventos
- Visualizar eventos cadastrados
- Editar informações dos eventos
- Excluir eventos
- Registrar compras realizadas
- Gerar relatórios financeiros
- Receber sugestões de eventos

## Como funciona?

Ao cadastrar um evento, o usuário informa o nome, tipo, data, local, orçamento e duração.

Todas as informações ficam salvas em um arquivo de texto, permitindo que os dados continuem disponíveis mesmo após o encerramento do programa.

Também é possível registrar compras relacionadas ao evento. Quando uma compra é adicionada, o valor é descontado automaticamente do orçamento disponível.
